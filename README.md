## ✨ Características Principales

Este cliente ha sido programado desde cero para garantizar que el juego fluya al máximo de su capacidad sin depender de navegadores externos:

- 🎮 **Aceleración GPU Forzada:** Aprovecha al máximo tu tarjeta gráfica para unos FPS estables.
- 💬 **Discord Rich Presence (RPC):** Muestra automáticamente a tus amigos de Discord que estás jugando a SpaceHunter.
- 📊 **Contador de FPS Integrado:** Monitorea tu rendimiento en tiempo real (Actívalo desde el menú superior).
- 🔄 **Actualizaciones Automáticas:** El cliente buscará y descargará silenciosamente las nuevas versiones sin que tengas que ir a la web.
- 🛡️ **Empaquetado Seguro (ASAR):** Sistema anti-manipulación que protege los archivos internos del juego.

## 📥 Instalación

Jugar a SpaceHunter V5 es más fácil que nunca:

1. Ve a la pestaña de [**Releases**](../../releases/latest).
2. Descarga el archivo `SpaceHunter-V5-Setup.exe`.
3. Ejecuta el instalador y sigue las instrucciones en pantalla.
4. ¡Inicia sesión y conquista la galaxia!
